## Meowww Lib

`Meowww` is a C library that provides useful functions and data structures to make development easier. The best part? It is a header-only library, you can simply copy the `meowww.h` file into your project and starting using `Meowww` lib. No setup required!

## Features

Here are the currently supported features.

+ String
+ Arrays (with custom data type support.)
